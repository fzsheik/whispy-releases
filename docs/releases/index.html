Whispy releases

Latest is v0.1.11, published 17 November 2026. Notes below are the GitHub release text. Where that text says “See CHANGELOG for details,” the only public changelog entry found on usewhispy.com is for 0.1.11. Older versions are not given features they did not publish.

These pages do not host installers, signatures, or latest.json. The desktop auto-updater uses the files on GitHub releases. File names and sizes are listed so you can see what each tag published. Open a version on GitHub from its heading.

v0.1.11

17 November 2026

Whispy v0.1.11

GitHub release note

See CHANGELOG for details.

Changelog on usewhispy.com for 0.1.11

The GitHub note points at the changelog. On 25 November 2026, usewhispy.com/changelog listed these items for 0.1.11, dated 2026-11-17. They are quoted, not rewritten.

  • Send recordings straight from your phoneClick Send from phone, scan the QR code and pick your files. They go straight to Whispy over your own Wi-Fi, never through the cloud. Free plans send one file at a time, Pro sends whole batches.
  • Speaker detection is twice as accurateNew speaker detection, powered by NVIDIA Nemotron-3, labels who said what twice as accurately, even in long meetings with up to 8 speakers. Everyone can try it once for free.
  • Teach Whispy your wordsAdd custom words and context before you transcribe, so names, jargon and brands come out right the first time. Works with Whisper and Qwen3-ASR, found under Advanced.
  • Send any transcript to your AIExport a transcript straight to ChatGPT, Claude or Gemini with your own instructions, for summaries, action items and rewrites. Transcription stays on your computer, and you choose what gets shared.
  • Best-in-class models for every regionParakeet Ultra now covers 25 European languages, and Qwen3-ASR brings top accuracy to Chinese, Japanese, Korean and more. Pick the model for your language in settings.
